# local.crmassigncascade 2.0.4

**Исполнитель: Vladislav**

Локальный модуль для коробочного Bitrix24: массовая смена ответственного и наблюдателей у компаний с опциональным применением к контактам, активным сделкам, смарт-процессам и новым счетам.

## Что делает модуль

Администратор выбирает компании в штатном списке CRM, указывает нового ответственного и наблюдателей и при необходимости отмечает связанные типы. После нажатия «Применить» модуль фиксирует точный список компаний в БД и ставит задание в очередь. Дальше браузер не нужен: обработку выполняет cron.

Каждое изменение проходит через штатный CRM D7 `Factory -> Item -> UpdateOperation` и записывается в журнал. После завершения инициатор получает системное уведомление Bitrix24 с итогами.

## Как работает

1. JS-адаптер добавляет действие в штатную панель групповых действий списка компаний.
2. Backend проверяет выбор и в одной транзакции создаёт job и фиксирует все ID компаний в `b_local_crm_assign_job_company`.
3. Пользователь сразу получает уведомление «Задача по смене поставлена в очередь».
4. HTTP завершается. Реальная обработка выполняется только cron-worker-ом.
5. Worker меняет CRM через `UpdateOperation`, а каждый CRM-элемент фиксирует в `b_local_crm_assign_log`.
6. После завершения пользователь получает системный отчёт в Bitrix24.

## Таблицы

- `b_local_crm_assign_job` — параметры одного массового задания и его статус.
- `b_local_crm_assign_job_company` — точный список компаний задания и очередь cron.
- `b_local_crm_assign_log` — подробный журнал CRM-элементов и защита от повторной обработки.

## Cron

```cron
* * * * * /usr/bin/php /home/bitrix/www/local/modules/local.crmassigncascade/bin/worker.php >>/var/log/local.crmassigncascade.log 2>&1
```

Один запуск обрабатывает до 25 компаний и работает не более ~50 секунд. `flock` не позволяет двум обычным cron-запускам выполнять очередь одновременно.

## Установка

1. Распаковать каталог в `/local/modules/`.
2. Установить модуль в административной части Bitrix24.
3. Добавить cron.
